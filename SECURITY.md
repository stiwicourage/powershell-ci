# Security policy

## Supported versions

Only the latest released tag of powershell-ci receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/stiwicourage/powershell-ci/security/advisories/new).
Do not open a public issue for a security problem.

Include the affected workflow or action, the tag, and the steps to reproduce.
You get an answer within 7 days, and a fix is released as a new tag.
